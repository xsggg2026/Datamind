================================================
  DataMind 使用说明（Mac 版 · 傻瓜式）
================================================

【你要做的事，总共 4 步】

第 1 步：解压
  下载得到的 zip 文件，双击它，会解压出一个文件夹。

第 2 步：把软件放进"应用程序"
  打开解压出来的文件夹，看到 DataMind 这个图标，
  把它拖到屏幕左侧 Dock 栏的"应用程序"（或访达里的应用程序文件夹）。

第 3 步：打开软件
  在"应用程序"里双击 DataMind。
  浏览器会自动打开分析页面（地址是 127.0.0.1:8787）。
  如果浏览器没有自动打开，就自己打开 Safari，
  在最上面的地址栏输入：127.0.0.1:8787 然后回车。

第 4 步：开始用
  在网页里粘贴基金报告网址，或上传 XML 文件，
  点"开始抓取并分析"，等十几秒，结果就出来了。

【第一次打开被拦截了怎么办？（很常见，不要慌）】

Mac 对所有不是从"App Store"下载的软件都会先拦一次，
这是系统的正常保护，不代表软件有问题，也不需要花钱。

情况一：提示"无法验证开发者"
  → 点"完成"或"取消"（不要点移到废纸篓）
  → 打开 系统设置 → 隐私与安全性
  → 往下翻，找到"DataMind 已被阻止"，点"仍要打开"
  → 输入你的开机密码（或指纹）

情况二：提示"DataMind 已损坏，应移到废纸篓"
  → 不要点移到废纸篓！
  → 打开"终端"（在 启动台 搜索"终端"两个字）
  → 复制粘贴下面这行命令，然后按回车：

    sudo xattr -rd com.apple.quarantine /Applications/DataMind.app

  → 会让你输入开机密码（输入时屏幕上不会显示任何字符，
    这是正常的），输完按回车
  → 再双击 DataMind 就能打开了

【Intel 还是 M 芯片？下载哪个版本？】

  点屏幕左上角的  苹果图标 → "关于本机"：
  * 看到"芯片 Apple M1/M2/M3/M4" → 下载 macos-arm64 版
  * 看到"处理器 Intel..."          → 下载 macos-x64 版

【日常使用】

  * 每次使用：双击 DataMind → 浏览器自动打开 → 用完关掉黑窗口/退出即可
  * 你的分析记录保存在：访达 → 前往文件夹 → 输入 ~/DataMind
    （软件删除后这些记录还在，重装软件也不丢）
  * 想备份或换电脑：把 ~/DataMind 文件夹整个拷贝到新电脑同样位置

【iPhone / iPad 用户】

什么都不用装。让帮你搭建服务的人给你一个网址，
用 Safari 打开 → 点底部"分享"按钮 → "添加到主屏幕"。
以后从主屏幕图标进入，和正常 App 一样用。

【最后一句话】

遇到任何提示都不要点"移到废纸篓"，
先看看本说明有没有对应的情况，实在不行找发软件给你的人。
